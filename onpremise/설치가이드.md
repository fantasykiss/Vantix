# Vantix On-Premise 설치 가이드

## 사전 요구사항

- Docker Desktop (또는 Docker Engine + Docker Compose)
- [Docker 다운로드](https://www.docker.com/products/docker-desktop/)

---

## 설치 순서

### 1단계 — 파일 준비

받은 `vantix-onpremise` 폴더를 서버에 복사합니다.

```
vantix-onpremise/
├── Dockerfile
├── docker-compose.yml
├── .env.example
└── 설치가이드.md   ← 현재 파일
```

---

### 2단계 — 환경변수 설정

`.env.example` 파일을 복사해서 `.env` 로 저장합니다.

```bash
cp .env.example .env
```

`.env` 파일을 열어 아래 항목을 채워주세요.

| 항목 | 설명 | 예시 |
|------|------|------|
| `REDMINE_URL` | 사내 Redmine 주소 | `http://redmine.company.com` |
| `REDMINE_API_KEY` | Redmine 관리자 API 키 | Redmine → 내 계정 → API 액세스 키 |
| `ANTHROPIC_API_KEY` | AI 기능용 API 키 | Anthropic Console에서 발급 |
| `ADMIN_PASSWORD` | Vantix 관리자 비밀번호 | 임의 설정 |
| `FERNET_KEY` | 데이터 암호화 키 | 아래 명령으로 생성 |

**FERNET_KEY 생성 방법:**
```bash
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

---

### 3단계 — 실행

```bash
docker-compose up -d
```

처음 실행 시 이미지 다운로드로 수 분 소요될 수 있습니다.

---

### 4단계 — 접속 확인

브라우저에서 접속합니다.

```
http://서버IP:8000
```

---

## 자주 쓰는 명령어

```bash
# 실행
docker-compose up -d

# 중지
docker-compose down

# 로그 확인
docker-compose logs -f app

# 재시작
docker-compose restart app
```
